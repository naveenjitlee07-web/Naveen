# Portfolio website
Open index.html to preview. Upload index.html, style.css, script.js and assets to your GitHub repository root. In Settings > Pages choose Deploy from a branch, main, / (root).

Add the original Figma portrait as assets/portrait.png and logo as assets/logo.svg. The Figma asset host was unreachable during creation. Add resume.pdf to assets. Add project-1.jpg through project-6.jpg to assets when available; the original frame contains blank project boxes and titles. Edit Work Title labels in index.html. About links to Core Expertise; Experience and Contact show a notice until real destinations are supplied. The stray phrase 'Is this conversation helpful so far?' was removed from the hero copy. Fonts load from Google Fonts with local fallbacks. Browser visual comparison was not performed.
